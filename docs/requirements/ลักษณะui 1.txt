MASTER UI/UX SPECIFICATION

1. เป้าหมายของ UI

ต้องการ UI/UX ที่ให้ความรู้สึกและความง่ายในการใช้งาน คล้าย ChatGPT

แต่:

- ห้าม Copy UI แบบ 1:1
- ห้าม Copy source code
- ห้าม Copy branding
- ห้ามใช้ Logo/ชื่อของ ChatGPT
- ให้ใช้หลัก UX ที่ดีในลักษณะเดียวกัน
- สร้าง Design System ของแอปเราเอง

แนวคิดหลัก:

«“เปิดแอป → เห็น Chat → พิมพ์สิ่งที่ต้องการ → AI เข้าใจและลงมือทำ”»

ผู้ใช้ทั่วไปต้องใช้งานได้ทันที โดยไม่จำเป็นต้องรู้เรื่อง:

- Model
- Agent
- Tool
- Runtime
- Terminal
- SDK
- Git
- Browser
- Build System

แต่ผู้ใช้ขั้นสูงต้องสามารถเปิดความสามารถเหล่านี้ได้ทั้งหมด
