---

0. คำสั่งสำคัญที่สุด

เรากำลังเริ่มพัฒนา Application ใหม่ทั้งหมดจากศูนย์

ห้ามนำสถาปัตยกรรมที่มั่วของ Application เดิมมาปะติดปะต่อโดยตรง

ให้ใช้เอกสาร/ความสามารถ/วัตถุประสงค์ของระบบเดิมเป็น "Product Requirements" เท่านั้น แล้วออกแบบ Architecture ใหม่ให้เป็นระบบเดียวกันตั้งแต่ต้น

จุดสำคัญที่สุด

Application นี้มีเป้าหมายเพื่อสร้าง "AI ของ Application เอง"

ไม่ใช่:

- แอป ChatGPT clone ที่แค่เรียก API
- แอปที่เอา Gemini/OpenAI/Qwen/Claude มาเป็น AI หลัก
- แอปที่ให้ผู้ใช้เลือก AI ของบริษัทอื่นแล้วจบ
- แอปที่มี Chat UI แต่ไม่มี AI Runtime ของตัวเอง

เป้าหมายคือ:

«สร้าง AI Runtime / AI Agent System ของเราเอง ตั้งแต่ระดับ Core → Memory → Planning → Tool Use → Execution → Verification → Learning/Improvement»

โมเดลภายนอกสามารถเป็น "Model Provider / Compute Provider" ได้ในอนาคต แต่ต้องไม่ถูกออกแบบให้เป็นตัวตนหรือสมองหลักของ Application
