# OWNER APPROVALS — การรับรองของเจ้าของโปรเจกต์

> บันทึกนี้เก็บคำรับรอง/การตัดสินใจของเจ้าของ (Owner) ที่มีผลผูกพันกับงานพัฒนา
> อัปเดตล่าสุด: 2026-09-24 (CP-139)

## 1. การรับรองรวมทุกอย่าง (Blanket Approval) — 2026-09-24

เจ้าของมีคำสั่งชัดเจนว่า **"อนุมัติทุกอย่าง"** ครอบคลุม:

| เรื่อง | คำรับรอง |
|---|---|
| สถาปัตยกรรมสุดท้าย (CP-55) | ✅ รับรอง — ถือว่าเซ็นแล้ว ไม่ต้องรอเซ็นแยก |
| นโยบายความเป็นส่วนตัว (AI ตอบตกลงเอง + เทเลเมทรีปิดค่าเริ่มต้น — CP-47) | ✅ อนุมัติตามที่ออกแบบไว้ |
| ขอบเขตงานที่เหลือ | ✅ ทำทั้งหมด: โมเดล AI เริ่มต้น (CP-139) + แปลงเสียงจากไฟล์ (CP-140) + อัดหน้าจอในแอป (CP-141) + เลเยอร์รูปภาพ (CP-142) + เทอร์มินัลเต็ม (CP-143) |
| วิธีเตรียมโมเดล AI เริ่มต้น | ✅ ดาวน์โหลดครั้งเดียวกดปุ่มเดียว (~400MB) — ไม่ดาวน์โหลดอัตโนมัติ |
| คุณภาพเสียงเป็นข้อความ (STT) | ✅ โมเดล base (~150MB) — แม่นกว่า tiny |
| การทดสอบบนอุปกรณ์จริง | เจ้าของทดสอบเอง — เอเจนต์รับผิดชอบโค้ด + CI เท่านั้น |

## 2. เงื่อนไขคงเดิม (Standing Rules)

- ห้ามบิลด์/เผยแพร่ APK รุ่น release จนกว่าเจ้าของจะสั่งชัดแจ้ง
- คุยกับเจ้าของเป็นภาษาไทยเสมอ
