# UI Reference — Video Editor

## Reference applications
CapCut, VN, KineMaster, Premiere Rush (layout concepts only).

## Observed
- Layout: top bar (back/project/export) · preview · timeline · tool tray.
- Navigation: project list → editor; tabs for media/audio/text/effects.
- Controls: playhead scrub, clip trim handles, split/duplicate/delete,
  speed, volume, filters, text styles, transitions.
- Interaction: tap select → inspector; drag trim; pinch timeline zoom.
- Gestures: horizontal scrub, pinch zoom, long-press menu.
- Responsive: portrait compresses panels; landscape expands timeline.

## Adopt
Preview + multi-track timeline + categorized tool tray; inspector on
selection; undo/redo + export always visible; render queue separate.

## Change
AI action sheet (auto-edit/silence/highlights/subtitles) wired to our
engine; timeline operations stay undoable via media.* tools; no
template-store/commerce UI.
