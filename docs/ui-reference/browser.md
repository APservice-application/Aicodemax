# UI Reference — Browser

## Reference applications
Chrome Android, Firefox Android, Samsung Internet, Brave (layout concepts only).

## Observed
- Layout: top tab control + address bar; page dominant; bottom optional bar.
- Navigation: tab switcher grid, ⋮ menu (tabs/history/downloads/settings).
- Controls: back/forward, omnibox (URL+search), reload/stop, tab count.
- Interaction: pull-to-refresh, find-in-page, text selection share, desktop toggle.
- Gestures: swipe on toolbar to switch tabs, pinch zoom on page.
- Responsive: portrait stacks; landscape widens toolbar.

## Adopt
Tab overview grid, omnibox behavior, ⋮ menu grouping, history/bookmarks/downloads
sections, find-in-page.

## Change
AI panel as bottom sheet (Ask AI) instead of separate assistant app; Add-to-project
and hand-to-chat as first-class actions; no account/profile sync UI.
