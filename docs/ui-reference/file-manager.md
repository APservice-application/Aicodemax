# UI Reference — File Manager

## Reference applications
Files by Google, Solid Explorer, Material Files (layout concepts only).

## Observed
- Layout: top bar (folder/search/view) · list/grid · bottom nav or drawer.
- Navigation: breadcrumb/folder drill, tabs for categories.
- Controls: sort, grid/list toggle, select, copy/move/rename/delete/share.
- Interaction: long-press selection mode with contextual toolbar.
- Gestures: swipe refresh, drag select (some).
- Responsive: grid columns adapt to width.

## Adopt
Folder drill + search + grid/list + sort; long-press multi-select with
Share/Copy/Move/Rename/Delete/More toolbar.
