# UI Reference — Image Editor

## Reference applications
Snapseed, Picsart, Lightroom Mobile (layout concepts only).

## Observed
- Layout: top bar (back/project/export) · canvas dominant · bottom tools.
- Navigation: tools → adjustment sliders → apply/discard.
- Controls: crop/rotate, tune (brightness/contrast/saturation), filters,
  healing, text, frames.
- Interaction: before/after hold, slider scrub, double-tap reset.
- Gestures: pinch zoom canvas, two-finger pan.
- Responsive: bottom sheet panels on portrait; side panel on wide.

## Adopt
Canvas-first layout, categorized bottom tools, slider adjustments with
before/after, layers as sheet/panel.

## Change
Tools map 1:1 to image.* gateway tools (crop/adjust/resize/rotate/
grayscale/restore/upscale); export via project outputs; no cloud presets.
