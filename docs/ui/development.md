# Development Workspace (+ Terminal)

Master spec §50–52.

## Inventory

- SCR-DEV-001 Workspace: Project · Run · ⋮ · file tree / code editor /
  bottom panel (Problems/Terminal/Git) — mobile shows one focus area at
  a time (§50).
- SCR-DEV-002 Editor: syntax highlight, line numbers, search/replace,
  selection, undo/redo, cursor nav, bracket match, file tabs, unsaved
  dot, error indicators; AI: Explain/Fix/Refactor/Generate/Test (§51).
- SCR-DEV-003 Problems: diagnostics list → jump to location.
- SCR-DEV-004 Terminal: `$ command / output / [input]`; a Tool, not the
  brain (§52). No manual Termux install.
- SCR-DEV-005 Run: run config + output + stop.

## Rules

Unsaved dot + [Cancel][Discard][Save] on exit (§86). Terminal sessions
survive switching (§89). AI invokes terminal through the tool API (§52).
