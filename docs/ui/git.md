## Inventory

- SCR-GIT-001 Main: Repository · Branch · Sync · ⋮.
- SCR-GIT-002 Changes: file list + diff + Stage.
- SCR-GIT-003 Commits: message + [Commit] (+ AI message assist).

- SCR-GIT-005 History: log + diff view (removed/added/context).
